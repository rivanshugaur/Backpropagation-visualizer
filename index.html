Question 1 Why does Binary Cross-Entropy (BCE) combined with a Sigmoid output produce the clean gradient (ŷ - y)?
▼

When candidates write backprop from scratch, a common rookie mistake is computing dL/dŷ and dŷ/dz separately and risking numerical division by zero. In reality, the mathematics cancel out perfectly:

1. Loss function: \(L(y, \hat{y}) = - [ y \ln \hat{y} + (1 - y) \ln (1 - \hat{y}) ]\)
2. Derivative w.r.t prediction: \(\frac{\partial L}{\partial \hat{y}} = - \frac{y}{\hat{y}} + \frac{1 - y}{1 - \hat{y}} = \frac{\hat{y} - y}{\hat{y}(1 - \hat{y})}\)
3. Sigmoid derivative: \(\frac{\partial \hat{y}}{\partial z_2} = \sigma(z_2)(1 - \sigma(z_2)) = \hat{y}(1 - \hat{y})\)
4. By Chain Rule: \(\frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} = \frac{\hat{y} - y}{\hat{y}(1 - \hat{y})} \cdot \hat{y}(1 - \hat{y}) = \mathbf{\hat{y} - y}\)

The denominator term \(\hat{y}(1 - \hat{y})\) cancels the exact derivative of the sigmoid function! This prevents gradient vanishing at the output layer when the network is wrong.

Question 2 What is the Vanishing Gradient Problem, and how can we visually identify it in this visualizer?
▼

The derivative of the standard Sigmoid function \(\sigma'(z) = \sigma(z)(1-\sigma(z))\) has a maximum value of 0.25 (at \(z=0\)). For Tanh, \(\tanh'(z) = 1 - \tanh^2(z)\) has a maximum of 1.0, but decays exponentially toward 0 as \(|z| > 2\).

By the multivariate chain rule: \[ \frac{\partial L}{\partial W_1} = X^T \left( (\delta_2 W_2^T) \odot f'(Z_1) \right) \] In a network with multiple layers, gradients are multiplied by \(\prod_{l} W_l^T f'(Z_l)\). If activations saturate, the gradients shrink exponentially with layer depth, meaning earlier layers learn virtually nothing.

How to demonstrate in this app: Look at the Layer Gradient L2 Norms card in Tab 1. If you switch activation to Sigmoid with a high initial learning rate or large weights, you will observe \(\|dW_1\| \ll \|dW_2\|\), proving that earlier layers stop receiving gradient signals!
Question 3 What is the "Dying ReLU" problem, and why was Leaky ReLU introduced?
▼

The derivative of ReLU is: \[ \text{ReLU}'(z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z \le 0 \end{cases} \] If a neuron's weights get updated such that \(z = X W_1 + b_1 \le 0\) for all training examples in the dataset, its gradient is identically 0. Because the gradient is zero, gradient descent will never change its weights again: the neuron is permanently dead.

Leaky ReLU fixes this by introducing a small slope \(\alpha \approx 0.01\) for \(z \le 0\), ensuring a non-zero gradient \(\frac{\partial L}{\partial z} = \alpha \cdot \frac{\partial L}{\partial a}\) always flows backward.

Question 4 Why is weight initialization critical? What happens if all weights are initialized to zeros?
▼

If all weights \(W_1\) and \(W_2\) are initialized to zero:

  1. All hidden units receive identical inputs \(Z_1 = 0 + b_1 = 0\).
  2. All hidden units output identical activations \(A_1 = f(0)\).
  3. During backprop, all hidden units receive identical gradients: \(\frac{\partial L}{\partial Z_{1, i}} = \frac{\partial L}{\partial Z_{1, j}}\).
  4. Consequently, all hidden units update to identical values. They never break symmetry, making the entire hidden layer behave as if it had only a single neuron!
Industry Solution: Xavier/Glorot initialization for Tanh (\(\sigma = \sqrt{2 / (n_{in} + n_{out})}\)) and He/Kaiming initialization for ReLU (\(\sigma = \sqrt{2 / n_{in}}\)) preserve variance across forward and backward passes.
Question 5 How does Numerical Gradient Checking mathematically validate analytical backpropagation?
▼

In production machine learning systems, autograd engines (like PyTorch or JAX) are rigorously verified using central finite differences: \[ \nabla_{\text{numerical}} \theta_i = \frac{L(\theta_i + \epsilon) - L(\theta_i - \epsilon)}{2\epsilon} \] We compare this against our analytical chain-rule gradient \(\nabla_{\text{analytical}}\) using relative error: \[ \text{Relative Error} = \frac{\|\nabla_{\text{analytical}} - \nabla_{\text{numerical}}\|_2}{\|\nabla_{\text{analytical}}\|_2 + \|\nabla_{\text{numerical}}\|_2} \] If the error is less than \(10^{-7}\), the analytical gradient implementation is mathematically verified down to machine floating-point precision.
